# Human Resource Management System (HRMS)

## Technologies
- Java Swing
- MySQL
- JDBC
- MVC Architecture
- DAO Pattern

## Features
- Employee Management
- Department Management
- Payroll Management
- Timekeeping
- Contract Management
- Statistical Reports

## How to Run
1. Import project into NetBeans / Intellij Idea
2. Execute hrms.sql
3. Configure DBConnection.java
4. Run HumanResourceManagement.java
